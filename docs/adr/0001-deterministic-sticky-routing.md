# 1 ADR 0001：确定性粘性路由

状态：已接受

日期：2026-08-25

## 1.1 背景

任务可能消耗订阅容量或外部美元，不透明的自动升级会放大成本、延迟与数据外发风险

## 1.2 决策

接单时使用版本化状态机选择一个供应商、一个模型和一个推理等级

首个输出或工具副作用出现后保持原路由

明确的 Schema 或检查规则失败时进入 `failed`，并返回 `validation_failed`

只有 `confirm` 权限预设在执行前进入 `awaiting_approval`，这项授权只决定是否启动 Runner，不判断模型输出质量

## 1.3 结果

每项任务能够重放路由决策并解释原因码

自动恢复范围缩小为同模型一次瞬时重试，规则失败需要调用方修改请求后显式重跑
